# RideWise — Customer Analytics & Churn Prediction Platform

An end-to-end internship project that predicts customer churn and segments riders for a ride-hailing platform.

## Features
- Customer feature engineering (RFM + sessions + tenure)
- Customer segmentation (Regular / Weekend / Occasional)
- Churn prediction model (Logistic Regression + Random Forest)
- FastAPI for real-time scoring
- Streamlit dashboard for KPI monitoring
- SQLite used for feature + metrics storage
